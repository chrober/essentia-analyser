# Essentia Analyser

Independent, offline Rust + original Essentia C++ audio-feature scanner.

The initial implementation is being migrated from `chrober/bliss-mood-poc` on a separate development branch. The former repository remains the independent research laboratory for music similarity and model evaluations. This default branch does not yet contain the scanner.

Native Essentia / FFmpeg and model redistribution are **not approved** until separate license and packaging reviews are complete.
